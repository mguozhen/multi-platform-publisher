## 三种 playbook 变体（发之前选一个）

### variant A — build 推文（最高频，60%）
今天 ship 了什么。
```
结构:
  第 1 行: [我 + 完成动词 + 具体产品]    昨晚 ship 了 wx-schedule
  中段:    [工具链命名公开化]            claude code → flatkey → 钉钉 API
  结尾:    [一个反直觉断言]              4 小时干掉了董事长的日历折磨
长度: < 280 字符 (免 Premium)
配图: 截图 / demo 录屏 / 终端
```

### variant B — 行业观察（25%）
一个判官式的行业断言。
```
结构 (Corey Haines 清单式):
  第 1 行: [一句可引用的断言]             LLM 中转站要死一半。
  中段:    [3-4 个 bullet, → 箭头]       活下来的三种 / → 跨厂商容灾 ...
  结尾:    [给从业者的命令]               其他都要换轨。
长度: < 280 (中文) / 可以更长走 thread
```

### variant C — shmidt 极简（15%）
两句对仗，标语级。
```
[外部现象]. [我] [动词] them.
  例: agents leave commits. i merge them.
长度: < 140 字符 → 触发大字号
```

## 钩子公式（开头第一行）

1. 「我 + 时间戳 + 完成动词 + 产品」— 昨晚 11:47 ship 了 X
2. 「X 要死一半」/「X 已经进入第 N 阶段」— 判官式
3. 「外部现象. i 动词 them.」— shmidt 式
4. 数字反差 — $1000/day from a $500 NAS

## tone 规则

- 英文小写为主（除专有名词）
- 0 emoji（中文圈可少量）
- 不教学（"我做了 X" 不是 "教你做 X"）
- 不解释，发完就走
- 个人号永不带购买链接

## 禁区

- ❌ "感谢支持" / "宝子们" / 鸡汤
- ❌ "AI 将重塑世界" 大词
- ❌ 政治敏感
- ❌ 装退休 / 装哲学家
