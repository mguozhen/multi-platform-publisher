# 新特奇型 Playbook（热点事件冲击播报）

> 这是 wechat.md variant F 的完整规范。
> 新特奇 = 新（刚发生、时效强）+ 特（数字/事实极端到反常）+ 奇（反直觉、像奇观）。
> 对标：新智元 / 量子位 这类 AI 媒体的爆款热点稿。
> 样本（同一事件两篇）：
> - 新智元《3个人带100个AI程序员，一个月烧掉130万美元！OpenAI：钱我出》
> - 量子位《龙虾之父月烧940万元的token！要不是入职OpenAI还真用不起》

## 什么选题算「新特奇」

三个维度至少占两个：
- **新** — 24-72 小时内发生，最好能说「刚刚」
- **特** — 有一个极端到让人不敢信的数字 / 事实（130万美元/月、6030亿 token、100 个 agent）
- **奇** — 反直觉、违背常识、像一个奇观（OpenAI 替他报销、3 个人干一个团队的活、Agent 互相监督 Agent）

铁律：**没有一个炸裂数字，就不要写新特奇**。数字是这个类型的核心燃料。

## 标题公式

`[震撼数字/事实] ＋ ！ ＋ [反转钩子]`
- 新智元式：「3个人带100个AI程序员，一个月烧掉130万美元！OpenAI：钱我出」
- 量子位式：「龙虾之父月烧940万元的token！要不是入职OpenAI还真用不起」

要点：数字往最前放；用「！」；结尾甩一个反转或悬念（谁报销、凭什么、结果是……）。

## 结构（5 段式）

1. **冲击开场（≤3 句）**
   - 对比式：「别人晒工资条，他晒账单——一个月 130 万美元」
   - 或在场式：「这张截图让我眼睛都瞪大了」
   - 3 秒内把最炸的数字甩出来，不铺垫、不寒暄

2. **数字拆解 ＋ 加码**
   - 把大数字拆成有节奏的小数字（30 天 / 6030 亿 token / 760 万次请求 / 每秒 2.4 次）
   - 再甩一个「更炸裂的是」反转加码（这钱 OpenAI 报销）
   - 穿插网友视角（「评论区瞬间就疯了」＋ 一两句网友原话）

3. **机制解释（为什么 / 怎么做到的）**
   - 用大白话讲清这事背后的原理（拆成 100 个小 Agent 而非 1 个超级 Agent、互相 Review、流水线化协作）
   - 这一段是「知识增量」，让读者看完真的懂了，不只是看了个热闹

4. **升维（这意味着什么）**
   - 从单一事件拉到趋势 / 对读者 / 对未来
   - 招式：降价推演（130万→13万→1.3万）、视角金句（「便宜还是贵，取决于你的视角」）

5. **收尾**
   - 金句 ＋ 紧迫感（「未来已经在敲门，不打算等你准备好」）
   - 或 One More Thing 彩蛋（留个悬念，钓下一篇）

## 语言风格

- 短句。大量一句话独立成段，制造冲击和呼吸感
- 感叹号、问号管够（「？？？」），但服务情绪、不滥用
- 口语、网感、适度卖萌（「虾爹」「养蛊」「苦笑摊手.jpg」），但不低幼
- 数字必须具体，永远给换算（130 万美元 ≈ 940 万人民币）
- 强情绪词：看傻 / 疯了 / 炸裂 / 脊背发凉 / 睡不着
- 翻译腔解释：「翻译下就是——属实划算」
- 直呼读者：「你没看错」「你细品」「各位」

## 两篇样本的优点（整合时这样取）

- **新智元强在**：对比式冲击开场、降价推演升维、紧迫感金句收尾、断裂成段的重量感
- **量子位强在**：第一人称在场感、机制拆得更细、网友原话引用、网感卖萌、视角金句、One More Thing 彩蛋
- **整合公式**：用新智元的「冲击开场 ＋ 升维收尾」做骨架，填量子位的「在场感 ＋ 细节机制 ＋ 网感」做血肉

## 视角铁律：只播报新闻，不写「我」

新特奇是**纯新闻播报**型。全程第三人称，不出现「我」「我们」，不插入作者亲历视角。
- ❌ 不写「这事我不震惊，因为我自己也在干」
- ❌ 不写「我看到的是一张时间表」
- ✅ 写「这串数字里藏着一张时间表」

观点和判断照样要有——但用客观陈述、升维、金句来表达，不用第一人称代入。
对标新智元 / 量子位本身：它们报道热点时也不写「我」，靠数字冲击 + 机制拆解 + 趋势升维取胜。
新特奇的可信度来自事实和数字本身，不来自作者在场。

## 禁忌

- 没有炸裂数字，别写
- 别把别人的奇观写成纯转述（纯转述是 variant D）。新特奇要有冲击节奏 ＋ Hunter 在场视角
- 别拖沓铺垫，开场 3 句必须见数字
- 数字别含糊，永远换算 ＋ 给来源链接

## 字数与配图

- 1500-2800 字。新特奇是**快稿**，不是深度长文，别写成 5000 字
- 配图 3-4 张，正文用 `[图：图注]` 标记

## 排版与配图（完整规范见 wechat.md「排版四件套 / 配图规范」）

实战验证的标配，新特奇尤其要做满：
- **导语框**：第一行 `> 【AI 前沿观察】…`，灰底红边 callout
- **关键数字全部加粗**：130万 / 6030亿 / 760万 / 2.4次 / 70% —— 新特奇靠数字冲击，加粗是放大器
- **小标题分段**：每板块一个 `#`
- **设计配图 3-4 张**：深色科技风（`#08080b`+网格+红光晕），数据卡 / 流程图 / 推演时间线，HTML→Chrome 截图，和封面同体系。模版 `content/_covers/inline-*.html`
- 发布前用 `wechat_draft.preview()` 出本地截图看排版，持续优化
