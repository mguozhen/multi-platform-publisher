# Podcast Playbook

> 平台: 播客（Apple Podcasts / Spotify，走 RSS feed 分发）
> 定位: 把深度文章 / 行业观察转成音频，覆盖通勤 / 碎片场景
> 频率: 每周 1-2 期

## 平台特性（2026 实测）

- 头部科技播客的成功要素:
  - **多人圆桌 / 对谈**最稳 —— 每个人贡献专业视角，信息量足又口语
  - **固定栏目段落**给每期结构感（如 Pivot 的「Win of the Week」「Predictions」）
  - 时长分场景:20-60 分钟访谈 / 也有 2 小时+ 的深度"音频纪录片"
  - 调性:**accessible yet authoritative** —— 把复杂话题讲清楚 + 给前瞻判断
- 排名看「多少不同用户在听」+ 完播率 —— 留住人比拉新更重要

## 单人播客怎么做（Hunter 起步形态）

solo 起步，不用等找到搭档:
- **固定开场**:一句话主题 + 本期三个看点
- **固定栏目**:本周最炸的一件事 / 拆一个观点 / 一个前瞻判断（对应公众号的新特奇 / 转述解读 / 行业观察）
- 口语化:不是念稿。把文章观点用"跟朋友聊"的方式重讲一遍
- 每期收一个 forward-looking 判断 —— 给听众"带走的东西"
- 时长:起步 12-20 分钟，单一主题讲透，不注水

## 内容来源

- 直接复用公众号深稿 / Substack 长文 → 改写成口语音频脚本（不是朗读原文，是重新口语化）
- 一篇深稿 = 一期播客脚本

## 生产链路

- 文章 → 口语化音频脚本 → TTS 配音（或真人录）→ 封面 → RSS feed 发布
- `multi-platform-publisher/podcasts/` 已有播客相关资产
- TTS 可走 flatkey / 现有语音克隆能力
