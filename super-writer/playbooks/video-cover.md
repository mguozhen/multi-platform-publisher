# 视频封面 Playbook

> 适用: 抖音 / TikTok / YouTube 视频的第一帧封面（决定点击率）
> 蒸馏来源: Hunter 2026-05-18 投喂的黑金营销海报样张

## 黑金爆款风（默认样式）

知识付费 / 商业爆款风。第一眼就要把人「钩住」。中文视频默认走这套。

### 视觉规范

- **画幅**：9:16 竖版 1080×1920（封面 = 视频首帧或单独封面图）
- **背景**：近黑深色（`#0a0e14`～`#11161f`）。压一张写实 AI 场景图打底
  （机器人 / 办公室 / 笔记本），暗化到只剩氛围，不抢标题
- **主标题**：超粗黑体，2–4 行，占画面上 2/3
  - 关键动作词用**亮黄高亮**（`#FFD400`）：黄底黑字色块，或纯黄字
  - 戏剧化的词加引号 +黄块强调（样张里的 `"删了"`）
  - 字号拉到极限，撑满宽度，字重 900
- **三点勾选**：黄色圆圈 ✓ + 3 个短词（4 字内），如 `自动引流 / 精准客户 / 持续成交`
- **主视觉**：一个写实 AI 机器人放右下，实拍质感（非扁平插画）
- **戏剧道具**：用一个视觉冲突讲故事 —— 样张是「垃圾桶丢『销售团队』纸条」。
  封面要有一个「冲突动作」，不只是堆字
- **底部 banner**：黄色毛笔刷色块，写一句利益点收尾（`解放人力，业绩翻倍！`）

### 配色

| 用途 | 色值 |
|---|---|
| 背景 | `#0a0e14` |
| 高亮黄 | `#FFD400` |
| 主文字 | `#ffffff` |
| 次要文字 | `#c8ccd4` |

### 文案公式

```
第 1 行   我把 [X]「[戏剧动作]」后，        ← 动作词带引号 + 黄块
第 2-3 行 [结果/反转]                       ← 关键词黄字
勾选三点  [短词] / [短词] / [短词]
底部 banner  [一句利益点]！
```

### 铁律

- 标题关键词必须有黄色高亮，纯白字封面点击率低
- 必须有一个「冲突动作」视觉（丢掉、删除、对比、爆炸式数字）
- 勾选点每个 ≤ 4 字
- AI 主视觉用写实渲染，不用扁平 icon
- logo / 平台名（OpenAI / Claude 等）在封面里要打码或不出现（小红书/抖音算法对外引敏感）

### 英文视频封面

同一套视觉，文案换英文，黄色高亮逻辑不变。例：
`I "FIRED" my sales team — then AI started closing 24/7`

## 实现

封面 HTML 渲染成 PNG：`chrome --headless=new --screenshot --window-size=1080,1920`。
样式存 `content/_covers/<topic>/cover.html`。视频首帧直接用这张封面定帧 1.5s。
