## 三种 playbook 变体（发之前选一个）

### variant A — 工具实操图文（推荐，最高频）
今天做了个工具，分步骤展示。
```
标题: [数字] + [反直觉] + emoji
      例: 4 小时做了个工具，让 AI 帮我约会议 🤖
正文: 800-1200 字
  首段 50 字内: hook + 一句话答案
  中段: 步骤分解 (每步配图)
  结尾: 一句行动指令
配图: 封面大字 + 6-9 张分步骤图
标签: #AI #ClaudeCode #AI工具 #生产力 + 长尾词
```

### variant B — 行业观察通俗版
把 X/公众号的硬观察翻译成小红书口语。
```
标题: Anthropic 一刀，LLM 中转站要死一半？🔪
正文: 1000-1500 字, emoji 分点, 口语化
```

### variant C — 董事长生活切片
一天的时间切片 / 设备 / 现场。
```
标题: 一个董事长的下午：写论文 → 开会 → ship 工具 → 飞东京
正文: 1000 字 + 实拍图
```

### variant D — 行业事件短评（蒸馏自@浅墨 momo「打不过就加入！Codex正式加入Claude Code」2344 赞）

抓一个 24h 内的行业事件 → 用一段 ~140 字的金句叙事弧讲清「态度」。**短文 carousel 形态**，不是长教程。
```
标题公式: [6字钩子+！]+[事件主谓宾陈述]
  例: 打不过就加入！Codex正式加入Claude Code
       不卷模型了！Anthropic 转身做支付
       别再爬数据了！这个免费 MCP 把评论扒到骨头

正文结构（5 段，每段 1-2 句，独立成段，~120-180 字总）:
  ① 引文学/影视/历史金句  例《三体》「弱小和无知不是生存的障碍，傲慢才是」
                          (《教父》《让子弹飞》《肖申克》《沙丘》都好用)
  ② 一句话解读事件        例 "OpenAI 没有因为自己是行业老大就固步自封..."
  ③ 升维一句              例 "这种开放心态，才是真正的强者思维。"
  ④ 用户视角钩子(转读者)  例 "而对我们用户来说，这简直是天大的好事。"
  ⑤ 网感金句收尾          例 "小孩子才做选择。成年人，当然是全都要。"

配图: 15 张 carousel
  - 1 张大字封面（标题主句 + 引文）
  - 中间 12-13 张：每段一张视觉锤（截图 + 标注 / 大字 / 数字）
  - 最后 1 张：「我在用 X」的现场图（终端 / 工具截图 / 设备）

标签: 8 个，混合英文小写 + 中文 + 1 个官方活动标签（蹭官方流量）
  例: #codex #claudecode #vibecoding #openai #Anthropic #独立开发者 #个人开发者 #RED新生代创作大赛
```

铁律（D 专属）:
- 第三人称叙事（评论事件），不像 A/C 是第一人称
- 总字数 < 200 字，超了就是 A 不是 D
- 必须有引语开场 + 金句收尾两个支点
- 「打不过就加入」「打都打不过」「再这样下去」「打了个措手不及」这种俗语放标题就出彩
- 一周不发超过 2 条 D（密集行业评论会显得只会蹭热点）

## tone 规则

- 标题必须有 emoji + 数字钩子
- 正文 emoji 适度（每段 1 个左右）
- 形象化，不要工程黑话堆砌
- 第一人称「我」

## 禁区（小红书算法严）

- ❌ 简介/正文不能挂外链
- ❌ 不写 "关注我" / "加微信"
- ❌ 截图里 logo 要打码（OpenAI/Claude 等被识别为外引）
- ❌ 新号每天 ≤ 2 条
- ❌ 不能出现 wx/qq/手机号
