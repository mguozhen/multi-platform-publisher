# 小红书 Playbook

> 平台: 小红书 @hunter_guo
> 工具: xhs-mcp CLI (自动发，已通)
> 角色: 流量入口 · 破圈口

## 核心定位

小红书是破圈平台 (3 亿 DAU)。男性董事长视角的 AI 内容在这里是蓝海。
用"一个董事长 + 一台 Mac + 11 个 AI 产品"的形象化叙事，不要工程师腔。

## 三种 playbook 变体（发之前选一个）

### variant A — 工具实操图文（推荐，最高频）
今天做了个工具，分步骤展示。
```
标题: [数字] + [反直觉] + emoji
      例: 4 小时做了个工具，让 AI 帮我约会议 🤖
正文: 800-1200 字
  首段 50 字内: hook + 一句话答案
  中段: 步骤分解 (每步配图)
  结尾: 一句行动指令
配图: 封面大字 + 6-9 张分步骤图
标签: #AI #ClaudeCode #AI工具 #生产力 + 长尾词
```

### variant B — 行业观察通俗版
把 X/公众号的硬观察翻译成小红书口语。
```
标题: Anthropic 一刀，LLM 中转站要死一半？🔪
正文: 1000-1500 字, emoji 分点, 口语化
```

### variant C — 董事长生活切片
一天的时间切片 / 设备 / 现场。
```
标题: 一个董事长的下午：写论文 → 开会 → ship 工具 → 飞东京
正文: 1000 字 + 实拍图
```

## tone 规则

- 标题必须有 emoji + 数字钩子
- 正文 emoji 适度（每段 1 个左右）
- 形象化，不要工程黑话堆砌
- 第一人称「我」

## 禁区（小红书算法严）

- ❌ 简介/正文不能挂外链
- ❌ 不写 "关注我" / "加微信"
- ❌ 截图里 logo 要打码（OpenAI/Claude 等被识别为外引）
- ❌ 新号每天 ≤ 2 条
- ❌ 不能出现 wx/qq/手机号

## 发布

```
xhs-mcp publish --type image \
  --title "标题" --content "正文" \
  --tags "AI,ClaudeCode,生产力,AI工具" \
  --media 封面图路径
时间: 22:00 (小红书黄金时段)
```
