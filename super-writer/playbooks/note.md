# note.com Playbook

> 平台: note.com — 日本最大的图文 / note 平台（3740万+ 文章）
> 定位: Solvea / VOC AI 的日本市场内容阵地
> 语言: 日文
> 频率: 每周 2-3 篇

## 平台特性（2026 实测）

- 日本国民级写作平台。有「有料記事」(付费文章) 文化 —— 深度内容可直接卖钱
- 平台和读者更看「记事是否真的被读完」(読まれているか)，而不是粉丝数
- 个人化、有温度、有「人となり」(人格感) 的内容吃香

## 怎么写

- **标题 + サムネ（缩略图）是命门**:入口设计要让人一眼"これはなんだ？"(这是什么？)
- **「なぜ〜なのか」式标题**:直白的「为什么会这样」型标题最契合 note
- **手绘图 / 手写图**:note 头部创作者爱用手绘图解释 —— 人格感和热量直接透出来。比精致信息图更有 note 味
- 个人化叙事:第一人称、真实经历、真实感受
- 深度 + 可读完性:结构清晰，让读者真的读到底（平台看完读率）
- 现在伸びる(增长中)的方向:AI 实操、个人 build、行业一线观察

## 爆款 note 文体（学自 fladdict 深津貴之，2597 LGTM）

note 上真正能爆的文体，和公众号、Substack 都不一样。9 条铁律:

1. **個人的な入り口で始める** —— 不要大上段的主张开头。用「最近こういうことを考えていて…」「本を出すので、その悩みなど」这种低姿态、私人的入口。
2. **超口语・亲密体** —— 「〜と思う」「〜な気がする」满篇,自虐(「外したらスマヌ」),直接对读者说话(「よかったら〜してちょ」)。是在跟朋友聊,不是在发表。
3. **一文一段、短い断定の連打** —— note 的换行节奏。一行一个想法。长段落是大忌。
4. **全文を貫く日常の比喩を一つ** —— fladdict 用「コンビニのプライベートブランド」讲透整个 AI 产业转移。复杂结构,要用一个生活化的比喻扛起来。
5. **小見出しは口语の疑問文** —— 「〜は本当か」「じゃあ、どうするか」。不要正式标题。
6. **予想は正直に明示** —— 「ここからは予想。外したらスマヌ」。不确定就说不确定。
7. **排比・反復で畳みかける** —— 「すでに〜。すでに〜。すでに〜。」节奏性重复推进。
8. **怖い部分から逃げない** —— 「ここがちょっと怖いところ」名指 dark scenario,直面它,再给出口。不粉饰。
9. **メタな再フレームで締める** —— 结尾把问题升维:「AIで何ができるか、ではない。AIが入った後の地図で、自分はどこに立つのか」。最后给读者一个明天就能用的姿势/orientation。

→ note 文章默认走这个文体（替代之前「## 怎么写」里偏说明文的写法）。日文,语气比 Substack 更「人」、更私人。

## Hunter 适配

- 日文写作。题材:Solvea/VOC AI 的日本市场故事、一个人用 AI 跑多产品、AI-Native 实践
- 风格:个人化、有温度，比英文 Substack 更"人"一点 —— 日本读者吃真诚和人格
- 配图:可用手绘风格图解（比深色科技信息图更 note）
- 长文可设为有料記事的前半免费 + 后半付费（note 原生变现）

## note 官方文体（蒸馏自 note 公式「家事のみかた」コンテスト告知 2040♡）

note 官方账号发文章那套，是 **明显模板化** 但有效。OSS / 工具 / 公告类文章都用得上:

1. **タイトルは行動動詞で締める** — 「〜を開催します！」「〜を公開しました！」「〜をリリースします！」。带感叹号 + 行动动词,告诉读者「这是一个事件」。
2. **冒頭は読者への直接の問いかけ** — 「『〇〇』と聞いて、みなさんは何を思い浮かべますか？」。不上来就讲产品,先把读者拉进话题。
3. **具体例の列挙** — 抽象名詞は禁。「料理、洗濯、掃除」「献立を考える、シャンプーを容器に詰め替える」具体的に列挙して共感を呼ぶ。
4. **隠れた〇〇 / 見えない〇〇 という再フレーム** — 既存の言葉に新しい視点を与える(「隠れ家事」「隠れた頑張り」)。「読者が気づいていなかった視点」を提示するのがフック。
5. **目次（TOC）を本文上部に置く** — 「目次」セクション + 飛び石用の H2 タイトル。長文でも読者が「全体像」を掴める。
6. **■ section headers** — `■テーマ・形式`/`■スケジュール`/`■賞` —— 不用 `##` markdown,用 `■` 全角四角作为视觉标记。note 编辑器原生支持 H2 但视觉上 `■` 更轻盈、更「note 公式感」。
7. **番号付きの応募方法** — (1)(2)(3) 的列举,note 用全角括弧。具体的步骤,降低读者参与门槛。
8. **協賛企業 / 信頼担保の段落** — Brand colab、合作 logo、引用机构。给读者「这事是真的」的信任锚。
9. **応募上の注意 / 細則** — 文末长长的细则段落,反而让读者觉得严肃认真。
10. **ハッシュタグキャンペーン** — #家事のみかた こういう官方タグ作って铺设。OSS 文章可以用 #個人開発 #AIエージェント 等。

→ **个人 essay** 走 fladdict 文体（前面 9 条）。**OSS 发布 / 公告 / 邀请 / 活动** 走这套 note 官方文体（10 条）。**两者不混用**,选其中一个。

## 发布

- note 无官方开放发布 API → 浏览器自动化（同 social-auto-upload 模式）
- **2026-05-19 起 note_publish.py 支持 `--auto-publish` 全自动模式** —— 填稿 + 自动点「公開に進む」+ 自动点「投稿する」+ 抓取已发布 URL
- 默认（不带 `--auto-publish`）仍是半自动: 填稿停在编辑页,用户审核后手动点。Auto 模式风险:无人审核,直接发出去不可撤回。仅在用户显式要求时启用。
